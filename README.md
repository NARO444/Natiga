# نشر الموقع على Vercel — خطوة بخطوة (من غير أي أوامر Terminal)

المجلد ده فيه كل حاجة محتاجها: الموقع نفسه (`index.html`) + السيرفر الصغير (`api/`) اللي بيرجّع النتائج. هننشرهم مع بعض في نفس الرابط، من غير ما تكتب أي كود.

---

## الخطوة 1: عمل حساب على GitHub (لو مفيش عندك)

1. روح على **https://github.com**
2. دوس **Sign up** واعمل حساب بالإيميل بتاعك.

> GitHub هنا هيبقى مجرد "مكان لتخزين الملفات" بس، مش هتحتاج تكتب أي أمر فيه.

---

## الخطوة 2: إنشاء Repository جديد (مكان لرفع الملفات)

1. بعد تسجيل الدخول، دوس على زرار **+** فوق يمين الصفحة → **New repository**.
2. اكتب اسم زي: `student-results`
3. سيبه **Public**.
4. **متعملش تحديد** على أي اختيار زي "Add README" — سيبها فاضية.
5. دوس **Create repository**.

---

## الخطوة 3: رفع الملفات (سحب وإفلات فقط)

1. في صفحة الـ repository اللي عملتها، هتلاقي رابط أو زرار مكتوب **"uploading an existing file"** — دوس عليه.
   (لو مش لاقيه، من فوق دوس **Add file → Upload files**)
2. افتح المجلد اللي معاك دلوقتي (اللي فيه `index.html`, `api`, `lib`, `package.json`).
3. **حدد كل الملفات والمجلدات دي مع بعض** واسحبها كلها لمنطقة الرفع في صفحة GitHub.
4. استنى لحد ما يخلص الرفع (شريط تقدم لكل ملف).
5. نزّل تحت وهتلاقي مربع كتابة، اكتب فيه أي حاجة زي "رفع الملفات" ودوس **Commit changes**.

---

## الخطوة 4: عمل حساب على Vercel وربطه بحساب GitHub

1. روح على **https://vercel.com**
2. دوس **Sign Up**، واختار **Continue with GitHub**.
3. وافق على الصلاحيات اللي هيطلبها (عشان يقدر يشوف الـ repositories بتاعتك).

---

## الخطوة 5: استيراد المشروع ونشره

1. من صفحة Vercel الرئيسية (Dashboard) دوس **Add New…** → **Project**.
2. هتلاقي قايمة بالـ repositories بتاعتك على GitHub، دوس **Import** جنب `student-results`.
3. Vercel هيكتشف تلقائيًا إن المشروع فيه Node.js — **متغيرش أي حاجة في الإعدادات**.
4. قبل ما تدوس Deploy، افتح **Environment Variables** وأضف:
   - `SUPABASE_URL` = رابط مشروع Supabase (مثال: `https://xxxx.supabase.co`)
   - `SUPABASE_SECRET_KEY` = المفتاح السري (Secret key) من Supabase → Settings → API
5. دوس **Deploy** وخد بالك بس، العملية هتاخد دقيقة أو اتنين.
5. لما تخلص، هتلاقي رسالة "🎉 Congratulations" ورابط زي:
   `https://student-results-xxxx.vercel.app`

---

## الخطوة 6: التجربة

1. افتح الرابط اللي طلع لك.
2. دوّر برقم جلوس زي `1024` أو اسم زي `أحمد`.
3. لو ظهرت النتيجة بشكل الشهادة بالختم والدوائر — يبقى الموقع والسيرفر شغالين مع بعض تمام، من غير ما تعدّل أي سطر كود.

---

## الخطوة 7: تحديث النتائج لاحقًا (لما تيجي نتيجة جديدة)

1. روح لـ **Supabase Dashboard** → **Table Editor** → جدول `students`.
2. عدّل أو أضف الصفوف (الأعمدة: `seat`, `name`, `total`, `status`).
3. التحديثات تظهر فورًا على الموقع — **مش محتاج** تعمل Deploy تاني.

---

## أسئلة شائعة

**هل محتاج أعدّل أي كود؟**
لأ. الموقع (`index.html`) متظبط أصلاً عشان يكلم السيرفر (`api/`) تلقائيًا لأنهم هيبقوا على نفس الرابط بعد النشر.

**من فين أجيب بيانات الطلاب الحقيقية؟**
ارفعها لجدول `students` في Supabase (Table Editor أو Import CSV). الأعمدة المطلوبة: `seat`, `name`, `total`, `status`.

**المجموع الكلي مش 320 عندي؟**
افتح ملف `lib/students.js` على GitHub (بنفس طريقة التعديل في الخطوة 7) وغيّر رقم `MAX_TOTAL` للرقم الصح، واعمل Commit.

**إعداد متوسط الدفعة (اختياري):**
لو عايز مقارنة «متوسط الدفعة» تظهر بدقة مع عدد كبير من الطلاب، شغّل ملف `sql/get_student_stats.sql` مرة واحدة من Supabase → SQL Editor.

**هل الموقع بيرجع كل الطلاب لو حد فتح رابط الـ API لوحده؟**
لأ، بيرجع طالب واحد بس مطابق للي اتكتب في البحث — البيانات باقي الطلاب مش ظاهرة لحد.
